# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/xiaoniaoyouhuajiang/Mathscape/security/advisories/new). Please do not disclose vulnerabilities, credentials, or private data in public issues or pull requests.

Include the affected version or commit, operating system, steps to reproduce, and the expected impact. Redact secrets and unnecessary personal information.

If the private reporting option is unavailable, ask a maintainer to arrange a private reporting channel without posting any vulnerability details publicly.
