# Desktop 阅读、任务与设置交互

## 来源目录

左栏可收起为窄栏；展开恢复原有内容和选择。折叠偏好保存在当前 WebView 的本地存储中，
不进入数学地图，也不作为 Workspace 的可移植知识数据。

## 设置与模型连接

顶栏始终显示“设置”。设置页包含运行策略和模型连接两部分。
模型连接列表区分新增、编辑和设为默认：保存不会隐式切换已有默认模型，第一份配置自动成为默认。
新配置使用独立 ID 与独立凭据引用；用户可填写、修改 `display_name`，旧配置缺少名称时显示模型 ID。
名称随 Profile JSON 保存于现有 SQLite 表，无须迁移数据库；API key 继续使用系统钥匙串。
`set_default_llm_profile` 只切换已存配置的默认状态，不接收或替换凭据。

Markdown 阅读页显示只读审核方式及“修改设置”入口。普通策略由后端启动时重新读取并确定；
“每次询问”在启动时弹出本次选择，可以取消。运行摘要记录有效策略，后续设置变更不改写已有任务。

## 任务浮窗

Discovery 调用通过 Tauri Channel 将 provider 实际公开返回的文本、推理摘要分片送到前端。
前端直接追加字符，不伪造思考、不人为延迟输出。没有 reasoning 分片时该区域为空。
等待响应、接收输出、验证、完成与失败分别反馈；流式输出仍是未验证材料。

浮窗由应用级单例管理任务 Promise，与阅读器生命周期分离，可最小化并通过右下角入口重新打开。
切换材料后，当前任务继续接收并保留最终结果。当前只保留最近一次任务，启动下一次任务会替换它；
退出或刷新应用后不恢复，任务历史和 SQLite 持久化仍待实现。
成功结果展示单元/关系数量，并可展开完整结果及验证诊断；阅读器尚在时仍展示原有提案卡片。

浮窗每个实时文本区域最多展示 200,000 字符，以控制 DOM 体积；完整结果仍由后端处理并返回。
任务仍受已配置总超时约束；断流或错误不在 UI 自动重试，也不将增量文本直接入图。

## 验证

浏览器覆盖新增/切换配置、启动时审核选择，以及输出到达后切换阅读材料、最小化和结果恢复。
Rust 覆盖 SSE 到观察回调、命名配置重开与默认切换、现有 Discovery 服务和凭据存储边界。
